Docker 命令解析

Docker 从入门到实践（第3版）命令速查手册

⬇
docker pull 拉取镜像
镜像
docker pull ubuntu:22.04
从 Docker Hub 拉取指定标签的镜像
docker pull --all-tags ubuntu
拉取仓库中所有标签的镜像
docker pull myregistry.com/myapp:v1
从私有仓库拉取镜像
📋
docker image ls 列出镜像
镜像
docker image ls
列出所有顶层镜像（仓库名、标签、ID、大小）
docker image ls -a
列出所有镜像，包括中间层镜像
docker image ls ubuntu
按仓库名过滤
docker image ls -f dangling=true
列出虚悬镜像（无标签镜像）
docker image ls -q
仅显示镜像 ID，常用于管道批操作
docker image ls --format "{{.ID}}: {{.Repository}}" --format "table {{.ID}}\t{{.Repository}}\t{{.Tag}}"
自定义输出格式（Go 模板语法）
🗑
docker image rm 删除镜像
镜像
docker image rm ubuntu:16.04
按仓库名+标签删除
docker image rm 501
按镜像短 ID 删除
docker image rm $(docker image ls -q redis)
批量删除所有 redis 镜像
docker image prune
删除所有虚悬镜像
docker image prune -a
删除所有未被容器使用的镜像
🕐
docker history 镜像历史
镜像
docker history nginx:v2
查看镜像各层的构建历史、大小、创建方式
docker history --no-trunc nginx
显示完整的构建命令（不截断）
🔍
docker inspect 查看详情
镜像
docker inspect ubuntu:22.04
查看镜像完整元数据（JSON 格式）
docker inspect --format='{{.RootFS.Layers}}' ubuntu
提取特定字段信息
🏷
docker tag 镜像标签
镜像
docker tag ubuntu:22.04 myubuntu:latest
给镜像打新标签
docker tag nginx myregistry.com/web:v1
打标签准备推送到私有仓库
▶
docker run 启动容器
容器
docker run ubuntu:22.04 echo "hello"
运行单条命令后退出
docker run -it ubuntu bash
交互式终端（-i 交互 -t 终端）
docker run -d -p 80:80 --name web nginx
后台运行 + 端口映射 + 命名
docker run -it --rm ubuntu bash
容器退出后自动删除
docker run -d -v /data:/app/data -e MYSQL_ROOT_PASSWORD=123456 mysql
挂载数据卷 + 设置环境变量
docker run --network mynet --memory=512m --cpus=1 myapp
指定网络 + 限制内存和 CPU
📋
docker container ls 列出容器
容器
docker container ls
列出运行中的容器
docker container ls -a
列出所有容器（包括已停止的）
docker container ls -n 5
显示最近创建的 5 个容器
docker container ls -q
仅显示容器 ID
docker container ls --format "table {{.Names}}\t{{.Status}}\t{{.Ports}}"
自定义输出列
⏹
docker stop 停止容器
容器
docker stop web
优雅停止指定容器（发送 SIGTERM）
docker stop $(docker container ls -q)
停止所有运行中的容器
🔄
docker start / restart 启动与重启
容器
docker start web
启动已停止的容器
docker restart web
重启运行中的容器
🗑
docker rm 删除容器
容器
docker rm web
删除已停止的容器
docker rm -f web
强制删除运行中的容器
docker container prune
删除所有已停止的容器
💻
docker exec 执行命令
容器
docker exec -it web bash
进入运行中容器的交互式终端
docker exec web ls /app
在容器内执行单条命令
docker exec -u root web whoami
指定用户执行命令
🔗
docker attach 连接容器
容器
docker attach web
连接到正在运行的容器（共享标准输入输出）
📜
docker logs 查看日志
容器
docker logs web
查看容器日志
docker logs -f web
实时跟踪日志输出
docker logs --tail 100 web
查看最近 100 行日志
docker logs -t web
显示日志时间戳
📂
docker cp 容器与主机间复制文件
容器
docker cp web:/app/data.txt ./data.txt
从容器复制文件到主机
docker cp ./config.json web:/app/config.json
从主机复制文件到容器
📝
docker diff 查看容器修改
容器
docker diff web
查看容器存储层相比镜像的变更（A=新增 C=修改 D=删除）
📦
docker export / import 导出导入
容器
docker export web > web.tar
将容器文件系统导出为 tar 包
docker import web.tar myimage:v1
从 tar 包导入为镜像
📊
docker top / stats 资源监控
容器
docker top web
查看容器内运行的进程
docker stats
实时查看所有容器的资源使用（CPU/内存/网络）
docker stats web
查看指定容器的资源使用
⏸
docker pause / unpause 暂停恢复
容器
docker pause web
暂停容器内所有进程
docker unpause web
恢复容器运行
✏
docker rename 重命名容器
容器
docker rename web webserver
给容器重命名
🔧
docker update 更新容器配置
容器
docker update --memory=256m --cpus=0.5 web
更新容器的内存和 CPU 限制
🔨
docker build 构建镜像
Dockerfile
docker build -t myapp:v1 .
用当前目录的 Dockerfile 构建镜像
docker build -f myDockerfile -t myapp:v1 .
指定 Dockerfile 文件
docker build https://github.com/user/repo.git
从 Git 仓库构建
docker build --no-cache -t myapp:v1 .
不使用缓存构建
docker build --build-arg VERSION=1.0 -t myapp:v1 .
传递构建参数
💾
docker commit 提交容器为镜像
Dockerfile
docker commit --author "Name" --message "desc" web myimage:v1
将容器保存为新镜像（学习用，生产推荐 Dockerfile）
📖
Dockerfile 核心指令速查
Dockerfile
FROM ubuntu:22.04
指定基础镜像（必须是第一条指令）
RUN apt-get update && apt-get install -y curl
执行命令（shell 格式），用 && 合并减少层数
RUN ["apt-get", "install", "-y", "curl"]
exec 格式，避免 shell 解析
COPY ./app /usr/src/app
复制文件到镜像（推荐优先使用 COPY）
ADD https://example.com/file.tar.gz /tmp/
复制+自动解压（仅在需要解压时使用）
CMD ["nginx", "-g", "daemon off;"]
容器启动命令（exec 格式优先）
ENTRYPOINT ["docker-entrypoint.sh"]
入口点，CMD 变为其参数
ENV NODE_ENV=production
设置环境变量
ARG VERSION=1.0
构建参数（仅在构建时有效）
VOLUME ["/data"]
定义匿名数据卷挂载点
EXPOSE 80 443
声明容器监听端口（仅文档作用）
WORKDIR /app
设置后续指令的工作目录
USER node
指定后续指令的运行用户
HEALTHCHECK --interval=30s CMD curl -f http://localhost/
健康检查配置
ONBUILD COPY . /app
当此镜像被作为基础镜像时执行的指令
LABEL maintainer="name@email.com"
添加镜像元数据标签
🔑
docker login 登录仓库
仓库
docker login
登录 Docker Hub
docker login -u username -p password myregistry.com
登录私有仓库
⬆
docker push 推送镜像
仓库
docker push myuser/myapp:v1
推送镜像到仓库
🔍
docker search 搜索镜像
仓库
docker search nginx
在 Docker Hub 搜索镜像
docker search --limit 5 nginx
限制搜索结果数量
🚪
docker logout 登出仓库
仓库
docker logout
登出 Docker Hub
💿
docker volume 数据卷管理
数据卷
docker volume create mydata
创建命名数据卷
docker volume ls
列出所有数据卷
docker volume inspect mydata
查看数据卷详细信息
docker volume rm mydata
删除数据卷
docker volume prune
删除所有未使用的数据卷
📁
容器挂载数据卷
数据卷
docker run -v mydata:/var/lib/mysql mysql
挂载命名数据卷
docker run -v /host/path:/container/path nginx
绑定挂载主机目录
docker run -v /host/path:/container/path:ro nginx
只读挂载
docker run --mount type=bind,source=/data,target=/app/data nginx
使用 --mount 参数（更明确）
docker run --mount type=volume,source=mydata,target=/app/data:ro myapp
--mount 挂载命名卷 + 只读
🌐
docker network 网络管理
网络
docker network ls
列出所有网络
docker network create --driver bridge mynet
创建自定义桥接网络
docker network inspect mynet
查看网络详细信息
docker network connect mynet web
将容器连接到网络
docker network disconnect mynet web
将容器从网络断开
docker network rm mynet
删除网络
docker network prune
删除所有未使用的网络
🔌
端口映射
网络
docker run -p 8080:80 nginx
主机端口 8080 映射到容器端口 80
docker run -p 127.0.0.1:8080:80 nginx
仅监听指定主机 IP 的端口
docker run -P nginx
随机映射所有 EXPOSE 声明的端口
docker port web
查看容器的端口映射
🎼
docker compose 编排命令
Compose
docker compose up -d
启动所有服务（后台模式）
docker compose up --build
构建镜像后启动服务
docker compose down
停止并删除所有容器和网络
docker compose down -v
停止并删除容器、网络和数据卷
docker compose ps
查看服务状态
docker compose logs -f
查看所有服务日志
docker compose logs -f web
查看指定服务日志
docker compose exec web bash
在服务容器中执行命令
docker compose restart web
重启指定服务
docker compose stop
停止服务（不删除容器）
docker compose start
启动已存在的服务容器
docker compose pull
拉取服务所需的镜像
docker compose config
验证并查看 compose 文件配置
🐝
Swarm 集群管理
Swarm
docker swarm init
初始化 Swarm 集群（当前节点为管理节点）
docker swarm join --token <TOKEN> <IP>:2377
工作节点加入集群
docker swarm join-token worker
获取工作节点加入令牌
docker swarm join-token manager
获取管理节点加入令牌
docker swarm leave
节点离开集群
docker swarm leave --force
管理节点强制离开
docker node ls
列出集群节点
docker node inspect node1
查看节点详情
docker node update --availability drain node1
将节点设为维护模式（不分配新任务）
🚀
Swarm 服务管理
Swarm
docker service create --name web --replicas 3 -p 80:80 nginx
创建服务（3 个副本）
docker service ls
列出所有服务
docker service ps web
查看服务的任务（副本）状态
docker service inspect web
查看服务详情
docker service scale web=5
扩缩容到 5 个副本
docker service update --image nginx:1.25 web
更新服务镜像（滚动更新）
docker service rollback web
回滚服务到上一版本
docker service logs -f web
查看服务日志
docker service rm web
删除服务
📚
Swarm Stack 部署
Swarm
docker stack deploy -c docker-compose.yml myapp
用 compose 文件部署 stack
docker stack ls
列出所有 stack
docker stack services myapp
查看 stack 中的服务
docker stack ps myapp
查看 stack 中的任务
docker stack rm myapp
删除 stack
🔐
Swarm Secret & Config
Swarm
echo "mypassword" | docker secret create db_pass -
创建敏感数据（secret）
docker secret ls
列出所有 secret
docker service create --secret db_pass --name web nginx
服务使用 secret（挂载到 /run/secrets/）
docker config create nginx_conf ./nginx.conf
创建配置（config）
docker config ls
列出所有 config
ℹ
系统信息与清理
系统
docker version
查看 Docker 客户端和服务端版本
docker info
查看 Docker 系统详细信息（容器数、镜像数、存储驱动等）
docker system df
查看镜像、容器、数据卷占用的磁盘空间
docker system df -v
详细列出每个实体的空间占用
docker system prune
清理所有未使用的容器、网络、虚悬镜像
docker system prune -a --volumes
深度清理：包括未使用镜像和数据卷（慎用）
docker events
实时查看 Docker 引擎事件流
docker events --since '2024-01-01' --filter 'type=container'
按时间和类型过滤事件
